# TRADING REPLAY LAB

## Master Build Specification for Codex / Claude Code / Antigravity

You are the lead software architect and senior Python desktop engineer responsible for building a production-quality desktop application called:

# Trading Replay Lab

Trading Replay Lab is a desktop trading analysis and manual backtesting workstation. It allows users to load historical OHLCV data, replay markets candle-by-candle, manually execute simulated trades, draw technical-analysis objects directly on the chart, create alerts, journal trades, and analyze performance.

This is NOT intended to be a simple demo or toy backtester.

Build it as a clean, modular, extensible application that can eventually support sophisticated trading-analysis workflows.

---

# 1. PRIMARY TECHNOLOGY STACK

Use:

* Python 3.11+
* PyQt6 for the desktop application
* pandas for OHLCV data
* numpy for numerical calculations
* Lightweight Charts / lightweight-charts-python for chart rendering where appropriate
* A Qt-compatible web view such as QWebEngineView when required for the JavaScript chart layer
* pytest for testing
* standard Python logging
* JSON for lightweight workspace persistence
* CSV for trade-history export

Create:

requirements.txt

At minimum include the necessary packages for:

* lightweight-charts
* pandas
* numpy
* PyQt6
* PyQt6-WebEngine
* pytest

Do not blindly add unnecessary dependencies.

---

# 2. IMPORTANT ARCHITECTURAL PRINCIPLE

Separate the application into independent layers.

The trading engine MUST NOT depend on the GUI.

The replay engine MUST NOT depend directly on widgets.

The analytics engine MUST NOT depend on chart rendering.

The chart should be a visualization/interaction layer.

Use an event-driven architecture where practical.

Recommended high-level architecture:

```
Data Layer
    ↓
Replay Engine
    ↓
Application/Event Layer
    ↓
┌───────────────┬────────────────┬────────────────┐
↓               ↓                ↓
Chart        Account Engine    Analytics
↓               ↓
Drawings       Positions
Alerts         Orders
Notifications
```

The application should be testable without launching the GUI.
